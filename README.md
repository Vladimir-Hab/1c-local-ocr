🚀 Локальное распознавание документов для 1С
УПД и ТОРГ‑12 за 30–60 секунд вместо 10–15 минут ручного ввода.
Фото, скан или PDF — всё обрабатывается прямо на вашем компьютере, без интернета.

📸 Как это работает
1. Загрузите документ
Подходит всё: фото с телефона, скан, PDF.
Даже если документ помят, с тенями или снят под углом.

2. Нажмите «Распознать»
Расширение автоматически определит тип документа (УПД или ТОРГ‑12), найдёт поставщика по ИНН, подберёт номенклатуру из вашего справочника.

3. Проверьте и проведите
Документ в 1С уже заполнен: реквизиты, табличная часть, суммы, НДС.

🔒 Почему локальный ИИ лучше облачных сервисов
Никаких отправок в интернет.  
Все документы обрабатываются локально — на вашем ПК или сервере.

Безопасность данных.  
Накладные, цены, ИНН, поставщики — всё остаётся внутри вашей сети.

Работает даже без интернета.  
ИИ не зависит от облака, API и внешних сервисов.
